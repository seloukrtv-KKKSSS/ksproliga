# Голи та картки зі складу

Після першого збереження завершеного матчу без технічної поразки адмінка розгортає тур і відкриває панель подій. Для вже завершених матчів відкрийте «Матчі → Голи та картки зі складу».

У панелі є списки обох команд, пошук і кнопки «+ гол», «+ жовта», «+ червона» біля гравця. Натискання одразу зберігає одну подію, оновлює список і підсумки гравця. Для кількох голів натискайте повторно після завершення збереження. Поточні лічильники стосуються цього матчу. Власний гол зараховується супернику при перевірці рахунку, але не збільшує голи автора.

Панель порівнює внесені голи з рахунком матчу та повідомляє про розбіжність. Вона не змінює рахунок. Списки подій нижче дозволяють видалити помилково внесений запис; наявні тригери бази автоматично коригують статистику.

Детальні форми залишають вибір гравця зі списку, хвилину, пенальті, автогол і другу жовту. Якщо склад опублікований, використовуються його гравці. Для команди без опублікованого складу доступні її вже створені профілі гравців. Нове ім’я спочатку додайте до складу команди.

Під час збереження й початкового завантаження кнопки недоступні. Помилка читання подій показує повторне завантаження та блокує швидке внесення, щоб не повторити вже збережену подію через застарілі лічильники.

Перевірено локально: додавання кількох голів одному гравцю, жовтих і червоних карток, пошук і відповідність рахунку. Регресійні перевірки: `pnpm test:match-events`, `pnpm test:players`, `pnpm test:players:sql`.
